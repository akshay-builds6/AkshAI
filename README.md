AkshAI — Personal AI Assistant

AkshAI is a work-in-progress personal AI assistant project developed by Akshay Yadav as a learning initiative.

Current Focus

- Python-based assistant architecture
- Flask API integration
- Modular engines for handling requests and responses
- Calculator, time, and weather-related functionality
- Improving reliability and user experience

Tech Stack

- Python
- Flask
- API integrations

Project Status

Work in Progress — features and architecture are still being developed and tested.

Goals

- Improve Python and software development skills
- Build a useful, modular personal assistant
- Learn responsible AI and API integration practices
